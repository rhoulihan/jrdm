# JRDM v0.4 — Live Oracle Preview + ETag Round-Trip Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use `superpowers:subagent-driven-development` (recommended) or `superpowers:executing-plans` to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A user can deploy a generated duality view to a connected Oracle instance, sample documents, edit a field and watch the ETag round-trip succeed, trigger a deliberate conflict (`ORA-42699`), and tear the sandbox schema down — all from the UI. This also closes carried debt **I3**: the duality `link` IR becomes asymmetric (`{ from, to }`) so real FKs with differently-named parent/child columns join correctly.

**Architecture:** Land **I3 first** as one atomic coordinated PR (model + generator + normalize + arbitrary + validator + web consumers — they are coupled by the workspace-wide `typecheck` job and the 10k round-trip property, so a partial rename breaks CI). Then build `@jrdm/exec` capabilities (read-capable sample, sandbox schema lifecycle, ETag edit, conflict simulator) each behind a real Oracle Testcontainers integration test (never mock Oracle — established rule). Then thin Fastify endpoints reusing the established Zod-validate → emit → connect → 502/422/400 pattern. Then the web preview surface (new `apps/web/src/preview/`), mocking only JRDM's own HTTP edge for deterministic UI tests (established rule). SSE for deploy progress is **deliberately out of scope** (YAGNI — synchronous JSON satisfies every acceptance criterion).

**Tech Stack:** Node 22, pnpm + Turbo monorepo, TypeScript strict, Zod, Fastify, `oracledb` ^6.6 (thin), `testcontainers` ^11 (Oracle Free `latest-lite`), React 18 + Vite 6 + Zustand 5 + Tailwind 3, Vitest 4 + @testing-library/react + jsdom (web unit), Playwright (e2e), fast-check (10k property). **No new runtime deps.**

## Conventions (inherited — do not relitigate)

- pnpm + Turbo monorepo. Branch/PR per task `feat/v04-<slug>` (or `refactor/`, `test/`, `docs/` prefix as fits). Poll CI to completion; merge `--squash --delete-branch` ONLY when `lint / typecheck / unit / integration / e2e` are all `success`. **`container` is a known non-blocking Trivy carry-forward — its `failure` does NOT block.** Then `git checkout main && git pull --ff-only`.
- Poll pattern: `for i in $(seq 1 120); do S=$(gh run list --branch <branch> --limit 1 --json status,conclusion --jq '.[0]'); echo "[$i] $S"; echo "$S" | grep -q '"status":"completed"' && break; sleep 20; done` then `gh run view <id> --json jobs --jq '.jobs[]|"\(.name): \(.conclusion)"'` then merge. **The `integration` job runs three Oracle Testcontainers suites and is ~15–25 min; poll up to 30 min.** Do NOT stop at "waiting for CI" — poll to completion and merge yourself. Oracle container startup can flake (we have hit `Hook timed out in 300000ms`); if `integration` fails ONLY on a container-startup/hook timeout and the diff is unrelated to that suite, `gh run rerun <id> --failed` once and re-poll — do NOT merge red, do NOT `--no-verify`.
- Test-pair gate (`.husky/test-pair-gate.mjs`): every staged `packages|apps/*/src/**.ts(x)` (except `index`) needs a stem-matched colocated test (`foo.ts → foo.test.ts` or `__tests__/foo.test.ts`) OR a `// @tested-by: <repo-rel-path>` first-line annotation whose named test is co-staged. **A modified source must have its colocated/annotated test staged in the same commit** — if a test file isn't otherwise changed, add a genuine new assertion so it legitimately co-stages.
- Coverage gates: `packages/*` ≥ 90 line / 85 branch; `apps/*` ≥ 70 / 65. Integration-only live-DB paths are exempt by the established rule (see `tasks/lessons.md` "Deploy live path is integration-covered by design") — only the irreducible Oracle-I/O path stays integration-only; pure logic (request shaping, error mapping, JSON tree building) gets unit tests.
- **Never mock external systems.** Oracle is exercised via real Testcontainers (`container-registry.oracle.com/database/free:latest-lite`, `Wait.forLogMessage("DATABASE IS READY TO USE!", 1)`, `withStartupTimeout(240_000)`, hook timeout `300_000`, connect as `system`/`JrdmTest_2026` to `…/FREEPDB1`). Web/e2e may mock JRDM's OWN HTTP endpoints for determinism (established rule).
- **Production DOM stays clean** (v0.2b/v0.3b lesson): scope test queries (`within`/`getByRole`/`getByTestId`); never fragment/restructure markup to satisfy a query.
- `gh` authed as `rhoulihan`, repo `rhoulihan/jrdm`. TDD strictly: failing test → red → minimal impl → green → commit. No backward-compat shims (global rule) — I3 is a clean rename, not an additive duplicate.

## Task 1: I3 — `link → { from, to }` atomic refactor

**Why one task:** the workspace `typecheck` turbo task and the 10k round-trip property both span model + generator + validator + web. A partial rename leaves `typecheck` or the property red on an intermediate PR. This is a coordinated rename with no backward-compat shim (global rule). Order steps tests-first so the new asymmetric contract is asserted red before the ripple.

**Semantics:** `link.from` = column(s) on the **parent** (enclosing) table; `link.to` = column(s) on the **child** (nested `f.table`). Equal length, min 1. SQL predicate: `childAlias.to[i] = parentAlias.from[i]` joined by `AND`. GraphQL: `@link(from : ["p1", …] to : ["c1", …])`. Symmetric old data has no migration path (no persisted projects in scope; examples are regenerated).

**Files:** model schemas + test; generator emit-sql-json, emit-graphql, normalize, arbitrary + all generator tests/golden fixtures; validator rules + test; web documentModel + test, FieldInspector + test.

```typescript
import oracledb from "oracledb";
import type { OracleConnectParams } from "./connect";

export interface QueryConnection {
  query<T>(sql: string, binds?: Record<string, unknown>): Promise<T[]>;
  execute(sql: string, binds?: Record<string, unknown>): Promise<number>; // rowsAffected, autoCommit
  close(): Promise<void>;
}

export async function openQueryConnection(p: OracleConnectParams): Promise<QueryConnection> {
  const c = await oracledb.getConnection(p);
  return {
    query: async <T>(sql: string, binds: Record<string, unknown> = {}) => {
      const r = await c.execute<T>(sql, binds, { outFormat: oracledb.OUT_FORMAT_OBJECT });
      return r.rows ?? [];
    },
    execute: async (sql: string, binds: Record<string, unknown> = {}) => {
      const r = await c.execute(sql, binds, { autoCommit: true });
      return r.rowsAffected ?? 0;
    },
    close: () => c.close(),
  };
}
```

```typescript
import type { QueryConnection } from "./query";

export class EtagMissingError extends Error {
  constructor() {
    super("EtagMissingError: document has no _metadata.etag");
    this.name = "EtagMissingError";
  }
}
type Doc = Record<string, unknown> & { _metadata?: { etag?: string } };

export function readDocSql(schema: string, view: string): string {
  return `SELECT JSON_SERIALIZE(data PRETTY) AS DOC FROM ${schema}.${view} WHERE JSON_VALUE(data,'$._id') = :id`;
}
export function writeDocSql(schema: string, view: string): string {
  return `UPDATE ${schema}.${view} v SET data = :doc WHERE JSON_VALUE(v.data,'$._id') = :id`;
}
export function etagOf(doc: Doc): string {
  const e = doc._metadata?.etag;
  if (!e) throw new EtagMissingError();
  return e;
}
export function stripMetadata(doc: Doc): Record<string, unknown> {
  const { _metadata, ...rest } = doc;
  void _metadata;
  return rest;
}

export async function readDocument(
  qc: QueryConnection,
  schema: string,
  view: string,
  id: string | number,
): Promise<Doc> {
  const rows = await qc.query<{ DOC: string }>(readDocSql(schema, view), { id: String(id) });
  if (rows.length === 0) throw new Error(`document _id=${id} not found`);
  return JSON.parse(rows[0]!.DOC) as Doc;
}

/** Writes the doc back. Oracle enforces the ETag automatically from the embedded
 *  _metadata.etag on the row; a stale doc → ORA-42699 (surfaced to caller). */
export async function writeDocument(
  qc: QueryConnection,
  schema: string,
  view: string,
  id: string | number,
  doc: Doc,
): Promise<{ etag: string }> {
  const affected = await qc.execute(writeDocSql(schema, view), {
    doc: JSON.stringify(doc),
    id: String(id),
  });
  if (affected === 0) throw new Error(`document _id=${id} not updated (not found or no-op)`);
  const fresh = await readDocument(qc, schema, view, id);
  return { etag: etagOf(fresh) };
}
```

> Note: Oracle JSON duality views carry the ETag inside the document's `_metadata.etag`. To update with optimistic concurrency you write the **whole document including the original `_metadata.etag`**; Oracle compares and raises `ORA-42699` on mismatch. So `writeDocument` is given the doc as read (mutated field, original `_metadata` intact) — do **not** strip `_metadata` for duality-view updates. `stripMetadata` is exported for the conflict simulator's "force a fresh write" path only.

```typescript
import type { QueryConnection } from "./query";
import { readDocument, writeDocument } from "./edit";

export function isEtagConflict(e: unknown): boolean {
  return /ORA-42699/.test(String(e instanceof Error ? e.message : e));
}

export interface ConflictOutcome {
  firstWriteEtag: string;
  secondWriteConflicted: boolean;
  error?: string;
}

/** Reads the same doc into two "tabs", writes tab A (succeeds, etag advances),
 *  then writes tab B with its now-stale _metadata.etag → expect ORA-42699. */
export async function simulateConflict(
  qc: QueryConnection,
  schema: string,
  view: string,
  id: string | number,
  mutate: (doc: Record<string, unknown>) => Record<string, unknown>,
): Promise<ConflictOutcome> {
  const tabA = await readDocument(qc, schema, view, id);
  const tabB = await readDocument(qc, schema, view, id); // same stale etag as A
  const a = await writeDocument(qc, schema, view, id, mutate({ ...tabA }));
  try {
    await writeDocument(qc, schema, view, id, mutate({ ...tabB }));
    return { firstWriteEtag: a.etag, secondWriteConflicted: false };
  } catch (e) {
    if (isEtagConflict(e)) {
      return {
        firstWriteEtag: a.etag,
        secondWriteConflicted: true,
        error: String(e instanceof Error ? e.message : e),
      };
    }
    throw e;
  }
}
```
