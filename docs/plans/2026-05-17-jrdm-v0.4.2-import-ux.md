# JRDM v0.4.2 — Import UX: ERD Layout, Draggable Nodes, Connect→Schema Picker

> **For agentic workers:** REQUIRED SUB-SKILL: Use `superpowers:subagent-driven-development`. Steps use checkbox (`- [ ]`) syntax.

**Goal:** Fix three real defects found using the live app: (1) imported tables stack in a single vertical column; (2) ERD nodes can't be dragged/repositioned; (3) there's no way to discover schemas — replace the free-text "Schema Owner" with a **Connect** button that lists available schemas in a dropdown, then **Import** pulls that schema's tables. Layout should prefer zooming out over clutter.

**Architecture:** `projectToGraph` gets a layout that never produces a single column: dagre for the FK-connected subgraph, a **grid** for isolated/edgeless tables, generous spacing. `DiagramPane` becomes a controlled React Flow graph (`useNodesState`/`onNodesChange`) so drags persist, re-seeding layout only when a _new_ import arrives (not on every store tick), with `fitView` + padding so big schemas zoom out cleanly. A new `listSchemas` in `@jrdm/importer-oracle` + `POST /api/schemas` route powers a Connect button in `ConnectionForm` that populates a schema `<select>`; Import uses the selected schema. Schema list = non-Oracle-maintained schemas that own at least one table (least clutter).

**Tech Stack:** unchanged — React 18 + @xyflow/react 12 + dagre, Zustand 5, Fastify 5, oracledb 6 (thin), Vitest+RTL+jsdom, Playwright, Testcontainers Oracle Free. **No new deps.**

- [ ] **Implement** `list-schemas.ts`:

```typescript
import type { QueryExec } from "./dictionary-sql";

// Non-Oracle-maintained schemas that own at least one table — least clutter.
export const LIST_SCHEMAS_SQL =
  "SELECT DISTINCT t.OWNER AS SCHEMA_NAME " +
  "FROM ALL_TABLES t JOIN ALL_USERS u ON u.USERNAME = t.OWNER " +
  "WHERE u.ORACLE_MAINTAINED = 'N' ORDER BY t.OWNER";

export async function listSchemas(exec: QueryExec): Promise<string[]> {
  const rows = await exec<{ SCHEMA_NAME: string }>(LIST_SCHEMAS_SQL);
  return rows
    .map((r) => r.SCHEMA_NAME)
    .filter(Boolean)
    .sort();
}
```
